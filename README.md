# Twelve Idea Clock HUD

A client-only clock HUD mod for Minecraft (NeoForge). Based on the original
[Clock HUD](https://github.com/QKninja/ClockHUD) mod, migrated to NeoForge 1.21.x
and rewritten in large parts.

## Features

- Display a clock bar on the HUD showing the current time of day (sun/moon).
- Show an animated "Day: N" counter at the start of each day.
- Toggle the clock with the `,` key by default.
- Position, scale, centered mode and day count can be configured in the mod's config screen.

## Installation

This is a **client-only** mod: it must be installed on the client and does not need
to be installed (and has no effect) on dedicated servers.

## Configuration

Config is registered as a CLIENT type config and can be edited in the Mods screen
(Mods > Twelve Idea Clock HUD > Config), or directly in
`config/twelveideaclock-client.toml`.
